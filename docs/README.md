# Indeks Dokumentasi

Folder `docs/` adalah lokasi khusus untuk dokumentasi project dan dokumen hasil generate yang penting.

## Status Dokumen

- Dokumen `aktif` adalah referensi utama untuk pengembangan dan operasional project.
- Dokumen `arsip` disimpan untuk konteks historis dan tidak boleh dijadikan acuan utama tanpa verifikasi ulang.

## Struktur Folder

- `overview/`
  - ringkasan project utama
- `guides/`
  - panduan setup, instalasi, dan operasional
- `analysis/`
  - hasil analisis teknis, audit, atau investigasi
- `checklists/`
  - checklist implementasi atau migrasi
- `standards/`
  - standar penulisan dan pengelolaan dokumentasi
- `templates/`
  - template dokumen baru agar format tetap konsisten
- `archive/`
  - dokumen lama, salinan, atau referensi historis

## Aturan Penamaan

- Gunakan nama file lowercase dengan format `kebab-case`.
- Nama file harus menjelaskan isi dokumen secara langsung.
- Dokumen hasil generate penting diletakkan di folder yang sesuai, biasanya `analysis/` atau `checklists/`.
- Dokumen arsip tetap boleh mempertahankan isi lama, tetapi harus diberi penanda yang jelas bahwa dokumen tersebut bukan referensi utama.

Aturan detail tersedia di [Standar Dokumentasi](standards/documentation-standards.md).
